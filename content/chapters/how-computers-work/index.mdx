## The parts

- **Processor (CPU)**: carries out simple instructions, such as add, compare and copy, billions of times a second.
- **Memory (RAM)**: fast working space that is wiped when the power goes off. A running program lives here.
- **Storage (disk)**: slower, permanent space for files.
- **Operating system**: Windows, macOS or Linux. It shares the hardware between programs and manages files.
- **Network**: how computers send data to each other.

## Everything is numbers

Computers store only on and off, written 1 and 0. One of these is a **bit**; eight make a **byte**, which can hold 256 different values. Numbers, text, images and sound are all encoded as bytes. Text uses an agreed table: in the common UTF-8 encoding the letter A is the number 65. A kilobyte is about a thousand bytes, a megabyte a million, a gigabyte a billion.

## What a program is

A **program** is a text file of instructions written in a **programming language**. The processor cannot read that text directly, so another program translates it. A **compiler** translates the whole file ahead of time into a fast machine-code file (C, Go, Rust). An **interpreter** reads and runs it line by line (Python, JavaScript), which is slower but quicker to work with.

```python
name = "Ama"
age = 20
print(name, "will be", age + 1, "next year")
```

Python runs this top to bottom: store a text, store a number, calculate, show the result. Every program, however large, is built from steps this small.

## Errors are part of the work

When code is wrong, the computer stops and prints an error message naming the line and the problem. This happens to everyone, all day. You cannot break your computer by writing bad code. Read the message, fix, run again.

## The layers you will hear about

**Front end**: what the user sees, in a browser or app. **Back end**: code on a server that holds the rules and talks to the database. **Database**: where data is kept. **Infrastructure**: the machines and networks it all runs on. A “full-stack” engineer works across all of them.
