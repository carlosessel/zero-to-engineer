## A program is a list of instructions

A computer is fast and obedient, and it understands nothing. It does exactly what it is told, one small step at a time. A **program** is a text file containing those steps. **Code** is the text. A **programming language** is the set of words and rules you are allowed to use so the computer can follow it. This course uses the language **Python**, because nearly all AI tools are built for it and it reads close to English.

```python
name = "Ama"
age = 20
print(name, "will be", age + 1, "next year")
```

Python reads this from top to bottom. Line one stores the text Ama under the label `name`. Line two stores the number 20 under `age`. Line three shows a message on screen, working out 20 + 1 on the way. The output is `Ama will be 21 next year`. That is programming: storing things, calculating, and showing or saving results. Everything later is built from pieces this small.

## Errors are part of the work

If you misspell a word or forget a quote mark, Python stops and prints an error message. This is normal. Professionals see errors all day. The skill is reading the message, which usually names the line and the problem, then fixing it and running again. You cannot damage your computer by getting code wrong.

## What the AI words mean

- **Artificial intelligence (AI)**: any software doing things that seem to need intelligence, such as understanding language or recognising a face.
- **Machine learning**: the main way AI is built today. Instead of a person writing every rule, the computer is shown many examples and works out the pattern itself.
- **Model**: the result of that learning. In practice it is a file full of numbers, plus a recipe for using them to turn an input into an output. “Training” a model means finding good numbers.
- **Neural network**: the most successful kind of model, loosely inspired by brain cells. Using big ones is called **deep learning**.
- **Large language model (LLM)**: a very large neural network trained on huge amounts of text to predict what comes next. Chat assistants are built on these.

Each one sits inside the one before: LLMs are a kind of deep learning, which is a kind of machine learning, which is a kind of AI.

## What you will be able to make

Programs that read documents and answer questions about them, sort and summarise messages, pull data out of photos, hold a conversation, search by meaning, and carry out multi-step tasks. You will mostly use models that already exist and write the code around them, and you will also train small ones yourself so you understand what is inside.

## How to learn this

- Type every code example yourself. Do not copy and paste at first; typing is how it sticks.
- After it works, change something and predict what will happen before you run it.
- When stuck for more than fifteen minutes, ask: the tutor box below, or a search for the exact error message.
- Little and often beats long and rare. Forty minutes a day is better than one long Saturday.
