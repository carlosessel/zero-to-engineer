The materials experienced database engineers and analysts recommend most often, grouped by the parts of this course. Almost all are free; the few that are not are marked. Every link was opened on 14 November 2026. Pick one for the part you are working on, and practise alongside it (<Ref to="db-projects" />).

## Learning and practising SQL

| Resource | Free? | Why use it |
|---|---|---|
| [PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html), the PostgreSQL project | Yes | The official introduction, from the people who build it. |
| [SQLBolt](https://sqlbolt.com/), SQLBolt | Yes | Short interactive lessons in the browser. |
| [PostgreSQL Exercises](https://pgexercises.com/), Alisdair Owens | Yes | Graded exercises on a club's bookings database, from simple to recursive queries. |
| [Select Star SQL](https://selectstarsql.com/), Zi Chong Kao | Yes | An interactive book working through a real dataset. |
| [SQL Murder Mystery](https://mystery.knightlab.com/), Knight Lab | Yes | Solve a crime with SQL: a fun way to practise joins. |
| [Window functions practice](https://www.windowfunctions.com/), windowfunctions.com | Yes | Exercises on the most important advanced feature. |
| [Modern SQL](https://modern-sql.com/), Markus Winand | Yes | Modern SQL features, explained with support across databases. |
| [DataLemur](https://datalemur.com/questions), Nick Singh | Free tier | Real interview questions from technology companies. |

## Design, performance and internals

| Resource | Free? | Why use it |
|---|---|---|
| [Use The Index, Luke](https://use-the-index-luke.com/), Markus Winand | Yes | The best explanation of indexes and SQL performance for developers. |
| [Don't do this](https://wiki.postgresql.org/wiki/Don%27t_Do_This), the PostgreSQL wiki | Yes | Common PostgreSQL mistakes, from the community. |
| [The Art of PostgreSQL](https://theartofpostgresql.com/), Dimitri Fontaine | No | Using SQL and PostgreSQL to their full power from applications. |
| [explain.dalibo.com](https://explain.dalibo.com/), Dalibo | Yes | Visualise and understand query plans. |
| [Crunchy Data tutorials](https://www.crunchydata.com/developers/tutorials), Crunchy Data | Yes | Hands-on PostgreSQL tutorials in the browser. |
| [Postgres.FM](https://postgres.fm/), Michael Christofides and Nikolay Samokhvalov | Yes | A weekly podcast on PostgreSQL performance and operations. |
| [CMU 15-445: Intro to Database Systems](https://15445.courses.cs.cmu.edu/), Andy Pavlo | Yes | How databases work inside, as a university course with videos. |
| [Database Internals](https://www.databass.dev/), Alex Petrov | No | Storage engines and distributed databases in depth. |
| [Designing Data-Intensive Applications](https://dataintensive.net/), Martin Kleppmann | No | The best book on how data systems work and fail. |
