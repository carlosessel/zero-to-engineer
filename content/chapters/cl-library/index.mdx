The best material for going further is Anthropic's own, because it is maintained alongside the products. Every link here was opened on 12 November 2026. Anthropic reorganises its sites from time to time; if a link has moved, search the documentation for its title.

## Courses

| Resource | What it is | Use it for |
|---|---|---|
| [Claude Academy](https://academy.claude.com/) | Anthropic's free courses: Claude 101, the AI Fluency series, Claude Code 101, Claude Code in Action, Introduction to Agent Skills, Introduction to MCP, Building with the Claude API, Introduction to Evals, and more | Structured practice alongside each part of this course |
| [Prompt engineering interactive tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial) | Hands-on prompting lessons with exercises | Practising the techniques in <Ref to="cl-prompting" />; written for older models, so the best-practices page wins where they differ |
| [Anthropic courses on GitHub](https://github.com/anthropics/courses) | Notebooks on API fundamentals, prompting, evaluations and tool use | Background reading; the repository is archived (read-only) and uses older models |
| [Claude Cookbook](https://platform.claude.com/cookbook) | Worked code examples for agents, tools, RAG, skills, caching, evaluations and more | Copying a working pattern when you build something |

## Keeping up

Things change monthly. Two habits keep you current without much effort:

- Read the [Claude Code changelog](https://code.claude.com/docs/en/changelog) and the [help centre release notes](https://support.claude.com/en/articles/12138966-release-notes) once a month.
- When a model changes, read its prompting page and rerun your evaluations before switching.
