## Well known, but not checked that day

These live outside GitHub and could not be opened when this list was made. Search for the name to find the current home.

- **CS50** (Harvard): the best-known free introduction to computer science.
- **Exercism** and **LeetCode**: practice problems, the first with free mentoring.
- **SQLBolt**: short interactive SQL lessons.
- **roadmap.sh**: the website version of the Developer Roadmap.
- Books: “The Pragmatic Programmer”, “Clean Code”, “Designing Data-Intensive Applications”, “A Philosophy of Software Design”. Check titles and editions before buying; these were listed from memory.

## How to use extra material without drowning

Finish a part of this course, then pick one resource for that stage and do its exercises. One finished course and several built projects beat ten bookmarked ones.
