Every item in the first table is a public GitHub project that was opened and confirmed to exist on 11 November 2026. It was not possible to review the full contents of each, so judge them as you go. The “stars” figure is how many GitHub users have bookmarked it, a rough public vote of confidence, rounded as of that date. Stars measure popularity, not correctness, so treat them as a guide.

## If you add only one thing per stage

- Learning Python: **30 Days Of Python**.
- Machine learning: **ML for Beginners** (Microsoft).
- Deep learning: **Neural Networks: Zero to Hero** (Karpathy).
- How language models work: **LLMs from scratch** (Raschka).
- Building applications: **Generative AI for Beginners** (Microsoft), plus your model provider’s own courses.
- Agents: **Hugging Face Agents Course**.
- Shipping: **Made With ML**.

## Well known, but not checked that day

These live outside GitHub and could not be opened when this list was made. They are long-standing recommendations; search for the name to find the current home.

- **CS50’s Introduction to Programming with Python** (Harvard): a full beginner course with lectures.
- **Kaggle Learn**: short hands-on courses in Python, pandas and machine learning, with free notebooks and GPUs.
- **Google’s Machine Learning Crash Course**.
- **Khan Academy**: free lessons and practice for all the school maths in this course.
- **3Blue1Brown** on YouTube: the clearest visual explanations of the maths and of neural networks.
- **fast.ai, Practical Deep Learning for Coders**: the video lectures that go with the fastai book.
- **DeepLearning.AI short courses**: one-hour courses on specific tools and techniques.
- **Your model provider’s documentation**: always the most current source for API details.

## How to use extra material without drowning

Finish a part of this course first, then pick one resource for that stage and do its exercises. Do not collect courses. One finished course and three built projects beat ten bookmarked ones.
