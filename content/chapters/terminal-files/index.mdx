## Files, folders and paths

A **file** holds data: a photo, a document, a program. Its **extension**, the part after the dot, says what kind: `.py` is Python code, `.txt` is plain text, `.csv` is a table, `.json` is structured data. A **folder** (also called a directory) holds files and other folders. A **path** is the address of a file, such as `Documents/ai-course/hello.py`.

## Opening the terminal

- **Windows**: press the Windows key, type “PowerShell”, press Enter.
- **Mac**: press Command and Space, type “Terminal”, press Enter.
- **Linux**: press Ctrl, Alt and T.

You see a line of text ending in a symbol like `$` or `>`. That is the **prompt**: it is waiting for you to type a command and press Enter. The terminal is always “in” one folder, called the current directory.

## The commands you need

| Command | What it does |
| --- | --- |
| `pwd` | Print the folder you are in now |
| `ls` | List what is in this folder (`dir` also works on Windows) |
| `cd Documents` | Move into the folder called Documents |
| `cd ..` | Move up one level, to the folder that contains this one |
| `mkdir ai-course` | Make a new folder called ai-course |
| `clear` | Clear the screen |

## Three time-savers

- Press **Tab** to auto-complete a file or folder name.
- Press the **up arrow** to bring back your previous command.
- Press **Ctrl and C** to stop a program that is running or stuck.

## Reading terminal errors

“command not found” means the name is misspelt or the program is not installed. “No such file or directory” means the path is wrong: run `pwd` and `ls` to see where you are and what is there.
