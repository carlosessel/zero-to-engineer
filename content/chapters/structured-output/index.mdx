## Ask for JSON, then validate

```bash
pip install pydantic
```

````python
# Uses client, MODEL and reply_text from "Your first model call".
import json
from pydantic import BaseModel, ValidationError

class Invoice(BaseModel):
    vendor: str
    total: float
    currency: str
    due_date: str | None

PROMPT = """Extract the invoice fields from the text below.
Reply with JSON only, using exactly these keys:
vendor (string), total (number), currency (3-letter code),
due_date (YYYY-MM-DD or null if absent).

<invoice>{text}</invoice>"""

def extract(text: str, tries: int = 3) -> Invoice:
    messages = [{"role": "user", "content": PROMPT.format(text=text)}]
    for _ in range(tries):
        msg = client.messages.create(model=MODEL, max_tokens=1000, messages=messages)
        raw = reply_text(msg).strip().removeprefix("```json").removesuffix("```")
        try:
            return Invoice(**json.loads(raw))
        except (json.JSONDecodeError, ValidationError) as e:
            messages += [{"role": "assistant", "content": reply_text(msg)},
                         {"role": "user", "content": f"That was invalid: {e}. Reply with corrected JSON only."}]
    raise ValueError("could not extract invoice")
````

<Walkthrough name="structured-output-retry" />

Three ideas are at work: a schema defines the contract, validation catches bad output before it reaches the rest of your system, and a retry feeds the error back so the model can fix it.

## Stronger guarantees

Anthropic's SDK can do the schema, the parsing and the checking in one call. You pass the Pydantic class, and the reply comes back already turned into a validated object:

```python
def extract_strict(text: str) -> Invoice:
    msg = client.messages.parse(
        model=MODEL, max_tokens=1000,
        messages=[{"role": "user", "content": PROMPT.format(text=text)}],
        output_format=Invoice,
    )
    return msg.parsed_output
```

Most providers offer features that constrain output to a JSON schema, and tool use (next chapter) is another reliable route to structured data. Check your provider’s documentation and prefer those when available. Validate anyway: well-formed JSON can still contain wrong values.
