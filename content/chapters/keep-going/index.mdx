## What stays true

Models predict from context. Give them the right context. Measure the result. Contain the failures. Every new technique is a variation on those four sentences.

## Habits

- Build something small every week. Ship it.
- Read provider documentation and release notes; they are the most accurate source.
- Read one paper a month. Start with the abstract, figures and conclusion. Begin with “Attention Is All You Need”.
- Write up what you learn. Teaching exposes gaps and gets you noticed.
- Contribute a fix or example to an open-source AI library.

## Getting hired

Employers want evidence you can ship. Lead with deployed projects, eval numbers, and honest write-ups of failures. Be ready to explain in an interview: how you would evaluate a system, how you would debug a bad RAG answer, how you would cut cost in half, and how you would defend against prompt injection. You can now answer all four.
