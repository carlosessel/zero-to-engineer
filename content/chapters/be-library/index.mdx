The materials experienced back-end engineers recommend most often, grouped by the parts of this course and by track. Almost all are free; the few that are not are marked. Every link was opened on 13 November 2026. You do not need all of them: pick one for the part you are working on, and read it alongside building something (<Ref to="be-projects" />).

## Start here

| Resource | Free? | Why read it |
|---|---|---|
| [roadmap.sh: back-end developer](https://roadmap.sh/backend), Kamran Ahmed and contributors | Yes | A map of the whole field, to see where each topic fits. |
| [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/), MIT | Yes | The shell, editors, Git, debugging and tooling that courses usually skip. |
| [Pro Git](https://git-scm.com/book/en/v2), Scott Chacon and Ben Straub | Yes | Everything about Git, from first commits to how it works inside. |
| [MDN: HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP), Mozilla | Yes | The reference for methods, status codes, headers, caching and CORS. |

## C# and .NET

| Resource | Free? | Why read it |
|---|---|---|
| [A tour of C#](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/), Microsoft | Yes | The official introduction to the language, with links to every feature. |
| [ASP.NET Core fundamentals](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/), Microsoft | Yes | Hosting, configuration, dependency injection, middleware, routing and logging in depth. |
| [Entity Framework Core](https://learn.microsoft.com/en-us/ef/core/), Microsoft | Yes | Modelling, querying, saving, migrations and performance. |
| [.NET Microservices: Architecture for Containerized .NET Applications](https://learn.microsoft.com/en-us/dotnet/architecture/microservices/), Microsoft | Yes | A free book on designing, building and running .NET services. |
| [eShop reference application](https://github.com/dotnet/eShop), Microsoft | Yes | A realistic multi-service .NET application to read and run. |
| [Andrew Lock's blog](https://andrewlock.net/), Andrew Lock | Yes | Clear, deep articles on how ASP.NET Core works inside. |

|---|---|---|
