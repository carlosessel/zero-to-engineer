## Install

- **Python 3.11 or newer** from python.org. On Windows, tick “Add Python to PATH” in the installer.
- **VS Code**, a free code editor. Add the Python extension when it offers.
- **Git** from git-scm.com, and a free account on GitHub.

Check each in the terminal:

```bash
python --version       # on Mac or Linux you may need: python3 --version
git --version
```

## Git: save points for your code

Git records snapshots of a project, called **commits**, so you can see what changed and go back. GitHub stores them online, which is both your backup and your public portfolio.

```bash
mkdir se-course
cd se-course
git init                          # start tracking this folder
# ... create a file hello.py in VS Code ...
git add .                         # choose what goes in the snapshot
git commit -m "Add hello script"  # take the snapshot, with a message
git status                        # what has changed since?
git log --oneline                 # history of snapshots
```

Commit small and often, with a message that says what changed and why.
